# ADR-0003 — Ruyi Logo as Yisi AI Primary Welcome Visual

## Status
Accepted

## Decision
Use the approved Ruyi logo as the primary central visual on Yisi AI's welcome/empty-session page.

Claude Code is a reference for interaction layout only; its mascot, branding, exact styling, copy, and proprietary assets are not reused.

## Reason
- strengthens RuyiSDK ecosystem identity
- avoids creating an unrelated mascot
- makes Yisi AI visually coherent with the final merged extension
- supports a clean closed-source product identity
